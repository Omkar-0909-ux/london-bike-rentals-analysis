# London Bike Rentals Analysis 🚲

This project analyzes London bike rental data using Python and Tableau.

## Workflow
1. Cleaned and prepared data in Jupyter Notebook using Python.
2. Exported the cleaned dataset to Excel.
3. Built an interactive Tableau dashboard to analyze:
   - Rental trends over time
   - Seasonal performance
   - Weekend vs weekday demand
   - Weather impact on rentals

## Tools Used
- Python (Pandas, Jupyter Notebook)
- Tableau Public
- Excel

## Output
- Cleaned dataset: `london_bikes_final.xlsx`
- Dashboard screenshot: `dashboard.png`

This project demonstrates an end-to-end data analytics workflow from raw data to business insights.
